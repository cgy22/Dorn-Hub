关于 Dorn Hub

一个 IP 的诞生

Dorn Hub 是一个网站，也是一个世界。它起源于初中教室里的一个玩笑，后来成长为一个完整的虚拟国家——𣿅国。这里有国歌、有总统、有文化、有历史，甚至有属于自己的文学经典。而这一切，都始于一个叫 Valéry 的人。

历史时间线

2019.9
灵感来源：Valéry
同班的 Valéry 是个矛盾体：身高 183，会法语、足球、小提琴，成绩优异——但上课吃东西、盒饭吃一周不扔、考试吃泡面撒到答题卡。这些行为成了项目创作的灵感源泉。
2021某月
洒水车事件
初中英语考试期间，窗外洒水车循环播放《兰花草》，噪音持续了整个下午，全班无法专心答题。有人开玩笑说：“我们要建一个国家，国歌就用《兰花草》。”
2021.10
“𣿅”字诞生
Léo 以 Valéry 为核心开始构建虚拟国家世界观。Valéry 真实姓名中有字眼与“𣿅”音近，而“𣿅”字本身来源于一次化学试卷的印刷错误。
基于洒水车事件，决定以《兰花草》为国歌。𣿅国虚拟国家概念正式确立，奉 Valéry 为大总统。
2022.2
羟基班
核心成员进入同一所高中的“强基班”（戏称“羟基班”）。班级内部关系紧密，为项目发展提供了土壤。
2022.3
Dornhub 创建
Léo 取“𣿅”的音译“Dorn”，创建 Dornhub 网页，用于介绍𣿅国世界观。域名 dornhub.github.io 诞生。同步发布的是“𣿅国国运模拟器”。
2022.4
cgy22 加入
Ade 向本班的 cgy22 介绍了该项目，把班级电脑的时钟时区命名为“𣿅国时间”。cgy22 表现出强烈兴趣，开始自学前端开发。
2022.5
Valéry 被甩
一个阳光明媚的星期五下午，Valéry 被女朋友甩了。Léo 是目击证人。
2022.9
Grabac 开始记录 · 第一次国宴
Grabac 开始模仿《论语》，用文言文记录 Valéry 与老师言行，称其为“𣿅子”。老师和同学都被抽象成“某子”。𣿅国诸子体系正式形成。
隔壁班 Debussy 带来一桶 2L 刺梨原汁到教室。味道极其奇特——酸到发苦。当天品尝者日后大多成为项目核心成员。称此为“𣿅国第一次国宴”。
2022.10
运动会加油稿
运动会要写加油稿，投稿就有机会上台公开朗读，而小语种稿件必定能有机会朗读，但是要有小语种老师签名审稿。见此，Léo 用𣿅语写了一篇加油稿，抓了一位同学，签了一个很潦草的名字假装老师签名。接稿的审核看不懂小语种，直接放行。于是 Léo 成功在主席台上推广了𣿅语。
2022.12
国庆节活动
Léo 制作𣿅国宣传海报，张贴在学校社团信息栏。首次公开宣传。对联是“建𣿅二载铸盛世，年方十六正青春”。团队正式成立。
2023.1
世界观页面重写
Léo 重写𣿅国世界观介绍页面，做了更完整的呈现（dornhub.github.io/index2）。
2023.3
班级电脑主页
cgy22 受启发，在 Dorn Hub 中加入搜索框和网页链接，设为班级电脑主页。现代 Dorn Hub 雏形诞生。
2023.4
独立域名
cgy22 学会部署网站，获得免费域名 dorn.rf.gd。Dorn Hub 拥有独立域名。
2023.5
《主干子》
Léo 开始记录地理老师的言行，命名为《主干子》——因地理老师上课要求 30 秒背完思维导图主干知识，背不出要唱歌。
2023.6
生化危机
Valéry 在某次市质检中生物和化学均获得班级第一。证明他平时不认真，但认真起来确实很强。
2023.8
作诗
Léo 曰：“刺梨醇香四溢，泡面沁芳十里。星环闪耀之处，𣿅国生生不息。”
2023.9
Grabac 完成《𣿅子》前三册
Grabac 完成高一阶段《𣿅子》三册记录。后续记录工作由 cgy22 接手。
2023.10
随机抽号器
各种随机抽号器在团队及班级之间开始盛行，不过它们都被调高了抽到 49 号的概率。49 号是 Valéry。
2023.11
“你去哪呀”
Valéry 逃美术课去实验楼玩原神，被监控拍到。美术老师将监控画面做成视频全年段公映。此乃：“头上三尺有监控，身前九寸是原神”。
2023.12
升旗仪式
OwenMeng 定制了一批𣿅国国旗，在𣿅国国庆节插在“支持𣿅国”的班级班牌上，称为“升旗仪式”。𣿅子 IP 进入快速传播期。
2024.2
第一次选举
𣿅国第一次全民总统及外阁选举举行。5 位参选人中，Valéry 以 50% 投票率胜选连任。
2024.3
版本3
cgy22 多次迭代，Dorn Hub 版本3 诞生。页面仍较为简陋（现可查看 dorn-old.dorn.rf.gd）。
2024.4
瓦莱西雅大辞典
Léo 大力开发瓦莱西雅大辞典（valencia.dorn.rf.gd），系统性整理𣿅国世界观词汇。cgy22 进行了改进。
2024.5
周边售卖活动
团队制作𣿅国周边在校内售卖，效果显著。活动成果的特别鸣谢现为“𣿅国名人堂”（dhof.dorn.rf.gd）。大𣿅子 IP 正式形成。
2024.6
虎扑评分
Valéry 在“虎扑名人堂”的评分和记录遭到删除。此前同学热衷于为其刷分。
2024.7
再次生化危机
Valéry 在期末考试再次发力，生物选择题只错了一道。
2024.10
总统故里
Léo 来到武平县。这是总统故里。Ade 曰：“富贵不归故乡，如衣锦夜行。”
2024.11
灵格斯
cgy22 为班级电脑里的电子词典软件“灵格斯”加入了𣿅国元素。这将成为“文化遗产”在高中永远流传。
2024.12
原神画册
今年没有𣿅国国庆庆典，不过团队给粉丝众筹了原神画册。
2025.1
版本4 诞生
cgy22 发现 mdui 框架，引入 Dorn Hub。外观和功能大幅提升，版本4 诞生（可查看 index-v4.3.html）。
2025.2
《𣿅子集校注》成书
cgy22 整理所有贡献者记录，集结成《𣿅子集校注》——模仿《论语》语录体，用文言文记录三年师生言行，相当于班史。在同学和老师间广泛传播，获认可。
2025.4
毕业合照
毕业合照时，cgy22 拍了 Valéry 的很多帅照。
2025.6
𣿅子外传
Léo 记录了些许 Valéry 的言行，作为《𣿅子外传》。
2025.7
高考结束
高考结束，团队成员各奔东西，进入不同大学。项目转为线上协作模式。
2025.8
漫展
Valéry 参加漫展，拍了很多集邮的照片。
2025.9
大学开学
团队成员分赴各地：上海、沈阳、青岛、南京、长沙、北京、厦门等地。线上成为主要协作方式。
2025.10
大香蕉
Léo 开发了基于 Unity 引擎的 3D 𣿅国游戏“逃离大香蕉”。
2025.11
版本5 诞生
cgy22 自研 UI 框架，Dorn Hub 版本5 诞生。外观焕然一新，代码质量显著提升。
2025.12
国宴规定
一个国宴规定逐渐产生：国宴菜品容器必须要是圆形的，左右各有两个弧形把手。
2026.1
豪华厕所
Léo 前往南京德基豪华厕所参观。
2026.2
地图
cgy22 发布了非常详细的电子版“2026年第六版𣿅国行政区划图”。
2026.3
最大规模更新
为交课程作业，cgy22 开始进行 Dorn Hub 史上最大更新。引入游戏、安全配置、多项功能，又搞到了一个好看的新免费域名 dornhub.eu.org。网站完善程度超过一些小型网站。
cgy22 开始编撰《后𣿅子集校注》，记录《𣿅子集校注》成书后 Valéry 的新事迹。
2026.4
DornGames
Léo 利用 DornGames 子团队，开发博饼、吃𣿅人等游戏，上线 dorngames.gamer.gd。
2026.5
DornGames 域名暂停
因 Léo 管理不善，dorngames.gamer.gd 域名被暂停，所有文件被托管方删除。
2026.6
开源
cgy22 在 GitHub 上开源 Dorn Hub 前端代码。
2026.7
瓦莱西雅大辞典3
假期， Léo 开发热情高涨，编写出了“瓦莱西雅大辞典”第三代，辞典词汇量破万。
2026.8
