 2026-10-22
这个版本来得很快，与上一个版本仅间隔了 1 天。原因在于今日，PHP 被发现了严重漏洞，对全球网站产生了安全影响。它被称为 “PHP2Shell”（CVE-2026-109618 与 CVE-2026-109619），是一个 CVSS 评分高达 9.2（严重）的远程代码执行漏洞。这个漏洞的根源在 PHP 语言核心（引擎）处理内存和请求的方式上，而不在我们的 PHP 脚本逻辑里。它主要影响允许用户上传文件（multipart/form-data）或者开启了 session.upload_progress 的服务器环境。我们的网站与服务器并不允许用户上传文件，这在我们的使用条款中也有表明。 我们服务器托管方的主机运行的是 CloudLinux 提供的 PHP 包，而 CloudLinux 尚未发布修复此漏洞的 PHP 版本。托管方正在等待他们提供包含安全修复的 PHP 版本。在此之前，为了保障托管环境和所有网站的安全，托管方已屏蔽某些请求无法到达 PHP，包括屏蔽所有 POST 请求和 multipart/form-data。目前，我们网站的 PHP 功能暂未受到影响。 在此情形下，我们仍然对网站所有的 PHP 文件进行了检查，重新改写了危险写法，修复了隐患，并将数据库数据从原先本服务器上的 MySQL 数据库迁移至了 Supabase 的 PostgreSQL 数据库。新数据库服务器与网站服务器位置同样处于英国伦敦，详情请查看隐私政策。 2026.10.22 CST 政策变动通知： 你好。2026.10.22 本网站已更新“隐私政策”。请前往 https://dornhub.eu.org/privacy-policy.html 查看。现有用户如继续使用 Dorn Hub 则代表同意上述条款。
