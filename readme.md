## 📁 What's Inside

| Folder | Purpose |
| :--- | :--- |
| 🌐 **/website** | Website documentation, screenshots, changelog (maybe not full source code) |
| 🎮 **/projects** | Games, tools, apps — each in its own subfolder |
| 📖 **/literature** | Lore, characters, worldbuilding |
| ⚙️ **/assets** | Shared files. Media, fonts, and more |
| 📄 **/templates** | Boilerplate files to help contributors |

---

## 🧭 Where to Start?

- **New here?** Start with `/literature` to explore the Donh universe
- **Want to play?** Browse `/projects` — each has its own README
- **Curious about the site?** Check `/website` for docs, or by visiting our Main website.

---

## 🤝 Contributing

Fan contributions are welcome!  
- **Lore:** Add or edit files in `/literature`  
- **Games/Tools:** Add a new subfolder in `/projects` with your code and a README  

Please keep all content respectful and on-theme for the Donh IP.

## 📁 仓库结构

| 文件夹 | 用途 |
| :--- | :--- |
| 🌐 **/website** | 网站文档、截图、更新日志（非完整源代码） |
| 🎮 **/projects** | 游戏、工具、应用 — 各自有独立子文件夹 |
| 📖 **/literature** | 世界观、角色、设定文档 |
| ⚙️ **/assets** | 共享文件：媒体、字体等 |
| 📄 **/templates** | 帮助贡献者上手的模板文件 |

---

## 🧭 从哪里开始？

- **初次来访？** 从 `/literature` 开始探索 𣿅国 宇宙
- **想玩游戏？** 浏览 `/projects` — 每个项目都有自己的 README
- **对网站好奇？** 查看 `/website` 里的文档，或直接访问主站。

---

## 🤝 如何贡献

欢迎粉丝贡献！  
- **世界观：** 在 `/literature` 中添加或编辑文件
- **游戏/工具：** 在 `/projects` 中新建子文件夹，放入代码和 README

请确保所有内容尊重原作，且符合 𣿅国 IP 的主题。
